SPIRAL INTENT / ARCHITECTURE

Worker ≠ Observer ≠ Verifier.

Spiral Intent places an independent verification boundary between authorized intent and consequential external effects.

INTENT → CORE → POLICY → WORKER → EXTERNAL STATE
                         ↓
                    OBSERVER (read-only)
                         ↓
                      VERIFIER
                         ↓
                 SIGNED RECEIPT → LEDGER
  • Policy signs a bounded authorization envelope or refuses.
  • Worker executes with write credentials only.
  • Observer reads external state through a separate read-only identity.
  • Verifier compares authorized effect with observed effect deterministically.
  • Ledger records signed receipts in an append-only hash chain.
