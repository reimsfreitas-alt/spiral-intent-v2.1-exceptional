SPIRAL INTENT / DOCUMENTATION

Execution assurance, with evidence.

Intent declares the desired action. Policy bounds and authorizes it. Worker executes. Observer independently reads external state. Verifier compares authorization and observation. Receipt captures the verdict. Ledger preserves an append-only hash chain.

CONFIRMED   authorized effect == observed effect
DEVIATED    authorized effect != observed effect
INCONCLUSIVE evidence insufficient

Offline verification is available through the receipt verifier. The current reference connector is for demonstration and testing.
