THE MISSING LAYER

A successful call is not a verified outcome.

Your agent, workflow engine, API gateway and application logs can all agree that a request succeeded. They still may not establish that the external state matches what was authorized.

The system that acts should not be the system that attests that it worked.

What existing systems report

Request accepted · HTTP 200 · operation ID · local state · worker status · trace completed.

What Spiral adds

Authorized effect · independent external observation · deterministic comparison · signed verdict · portable receipt.

TRUST BOUNDARIES

The separation is the product.

The system that writes is not the authority that attests. Worker, Observer and Verifier remain separate functions.

WORKER ≠ OBSERVER

Who writes does not receive authority to attest to the work.

OBSERVER ≠ VERIFIER

Observation and verdict remain distinct functions.

EVIDENCE, NOT A PROMISE

Four explicit outcomes.

CONFIRMED

Observed effect corresponds to authorized effect.

DEVIATED

Observed effect does not correspond to authorization.

INCONCLUSIVE

Evidence is insufficient; absence of proof is not confirmation.

CONFLICTED

Valid observation sources disagree; conflict is not silently collapsed.
