THE MISSING LAYER

A successful call is not a verified outcome.

Your agent, workflow engine, API gateway and application logs can all agree that a request succeeded. They still may not establish that the external state matches what was authorized.

The system that acts should not be the system that attests that it worked.

What existing systems report

Request accepted · HTTP 200 · operation ID · local state · worker status · trace completed.

What Spiral adds

Authorized effect · independent external observation · deterministic comparison · signed verdict · portable receipt.

TRUST BOUNDARIES

The separation is the product.

Each authority gets the minimum power needed for its role. The executor does not own the observation, and the observer does not own the attestation.

AUTHORITY 01

Policy

Defines what may happen and issues a bounded authorization.

POLICY → evaluate
SCOPE → limit
AUTH → sign
AUTHORITY 02

Execution

Applies the action with write authority to the external system.

WRITE → external effect
CLAIM → report result
VERIFY KEY → unavailable
AUTHORITY 03

Observation & Verification

Reads the external state independently and emits the verdict.

READ → external state
COMPARE → authorized ↔ observed
RECEIPT → sign
Threat-model discipline: Spiral does not claim that one Observer can never be compromised. It claims a narrower, testable property: a compromised executor does not acquire the independent verification authority merely by controlling execution.

VERDICTS

No false certainty.

The verification layer must distinguish a real mismatch from insufficient evidence. A timeout is not a confirmation. A successful worker claim is not a fact.

CONFIRMED

The observed effect corresponds to the authorized effect under the stated observation policy.

DEVIATED

The observed external effect does not correspond to the authorized effect.

INCONCLUSIVE

Evidence is insufficient to determine the outcome. Uncertainty remains uncertainty.

WHERE SPIRAL FITS

Above the system that executes. Below the business consequence.

Spiral is intentionally agnostic to the actor: agent, workflow engine, script, service or human-triggered automation. The primitive is the consequential action and the proof of its effect.
